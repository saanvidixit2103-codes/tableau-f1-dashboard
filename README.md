# Formula 1 Race Intelligence Dashboard

Interactive Tableau dashboard and data story on Formula 1 driver performance, team strategy and championship trends, presented on a custom React website.

**Live site:** https://formula-1-race-intel-ok3s.bolt.host

**Tableau Public:** https://public.tableau.com/app/profile/saanvi.dixit2179/viz/shared/6NWQ3TC4W

Built with React, Vite, Tailwind CSS and Tableau Public.
